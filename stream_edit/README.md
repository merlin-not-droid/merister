# 치지직 다시보기 → 20분 유튜브 편집 가이드 (Premiere Pro)

대상: https://chzzk.naver.com/video/15940407

> **현재 상태** — 이 작업 환경의 네트워크 정책이 치지직(`chzzk.naver.com`, `api.chzzk.naver.com`, `apis.naver.com`)을
> 막고 있어 영상과 채팅을 아직 열어 보지 못했습니다. 그래서 이 문서에는 **이 영상 전용 타임스탬프가 아직 없습니다.**
> 영상 내용과 상관없이 정할 수 있는 구성·컷 기준·효과 레시피·프리미어 작업법을 먼저 정리했고,
> 어느 구간을 쓸지는 [`chzzk_highlights.py`](chzzk_highlights.py)가 채팅 반응으로 후보를 뽑도록 했습니다.
> 접근이 열리면 [9장 컷 리스트](#9-이-영상-컷-리스트)를 실제 시간으로 채웁니다.

메뉴 이름은 Premiere Pro 2024~2025 한국어판 기준이고 영어 이름을 괄호에 같이 적었습니다. 단축키는 Windows 기준
(Mac은 Ctrl→Cmd, Alt→Option).

## 0. 작업 순서

| 단계 | 할 일 | 결과물 | 대략 시간 |
|---|---|---|---|
| 1 | 원본 받기 · 점검 (VFR, 확장자) | 편집 가능한 mp4 | 30분 |
| 2 | 하이라이트 후보 뽑기 (`chzzk_highlights.py`) | `highlights.md`, 셀렉트 시퀀스 XML | 10분 |
| 3 | **1차 셀렉트** — 후보 검토 + 흐름에 필요한 구간 추가 | `01_셀렉트` 35~45분 | 1~2시간 |
| 4 | **러프컷** — 순서 배치, 콜드 오픈 | `02_러프컷` 24~26분 | 1~2시간 |
| 5 | **파인컷** — 점프컷, 공백 삭제 | `03_파인컷` 20~21분 | 2~3시간 |
| 6 | 자막 | | 2~4시간 (가장 오래 걸림) |
| 7 | 효과 · 효과음 · BGM | | 2~3시간 |
| 8 | 음량 마감 → 내보내기 → 검수 → 업로드 | mp4, srt, 챕터 | 1시간 |

압축 비율 감각: 원본 3시간 → 셀렉트 40분(22%) → 러프컷 25분 → 최종 20분(11%).
처음부터 20분을 맞추려 하지 말고 **넉넉히 고른 뒤 단계마다 깎는** 쪽이 빠르고 결과도 좋습니다.

## 2. 컷 기준

| 판단 | 대상 |
|---|---|
| **무조건 삭제** | 방송 시작 대기 화면, 세팅 · "소리 들려요?", 로딩 · 매칭 대기, 자리 비움, 의미 없는 채팅 인사 읽기, 같은 말 반복, 방송 사고(재밌으면 예외), 개인정보 노출, 혐오 · 비하 발언, 시청자 저격, 저작권 음악 |
| **압축** (배속 · 몽타주 · 요약 자막) | 반복 플레이(파밍 · 연습), 긴 이동, 긴 설명, 결과는 중요한데 과정이 긴 도전 ("도전 17회차" 카운터 + 시도 3~4개만) |
| **유지** | 채팅이 폭발한 순간(ㅋㅋ · ㄷㄷ · 클립 요청), 스트리머 리액션이 큰 순간(비명 · 폭소 · 정색), 시작-위기-결과가 있는 덩어리, 썸네일이 될 장면 |

- **설정 → 결과를 같이 남깁니다.** 펀치라인만 자르면 맥락이 없어서 안 웃깁니다. 보통 사건 10~40초 전부터 필요하고,
  그래서 `chzzk_highlights.py`도 채팅 반응 40초 전부터 구간을 잡습니다.
- **채팅이 안 터져도 흐름상 필요한 장면**(목표 설명, 결과 발표)은 짧게 넣습니다. 이 장면들은 채팅 분석으로 안 잡힙니다.
- **내부 밈**은 상황 설명 자막 한 줄로 살릴 수 있으면 유지, 설명이 두 줄 넘게 필요하면 삭제합니다.

## 3. 프리미어 준비

### 3.1 원본 받기 · 점검

1. **원본 확보** — 본인 방송이거나 스트리머에게 편집 허락을 받은 영상만 씁니다. **OBS로 함께 녹화한 파일**
   (기본 이름이 `2026-10-30 23-07-44.mp4`처럼 녹화 시작 시각)이 있으면 그걸 씁니다. 보통 다시보기보다 화질이
   같거나 좋습니다. 녹화본이 없으면 다시보기를 받습니다 —
   [yt-dlp](https://github.com/yt-dlp/yt-dlp)가 치지직을 지원합니다 (19세 영상은 `--cookies-from-browser chrome` 필요):
   ```bash
   yt-dlp -o "%(id)s.%(ext)s" https://chzzk.naver.com/video/15940407
   ```
2. **`.ts` 파일이면** mp4로 바꿉니다 (재인코딩 없음, 몇 분):
   ```bash
   ffmpeg -i 15940407.ts -c copy -movflags +faststart 15940407.mp4
   ```
3. **가변 프레임레이트(VFR) 확인** — 방송 녹화본은 프레임 드랍 때문에 VFR인 경우가 있고, 프리미어에서 뒤로 갈수록
   입 모양과 소리가 어긋납니다. `chzzk_highlights.py --vod`로 돌리면 자동으로 경고하고, MediaInfo에서
   "Frame rate mode: Variable"로도 확인할 수 있습니다. VFR이면 고정 프레임레이트로 바꿉니다 (NVIDIA 그래픽카드면
   `-c:v h264_nvenc -cq 19`가 훨씬 빠름):
   ```bash
   ffmpeg -i 15940407.mp4 -fps_mode cfr -r 60 -c:v libx264 -crf 18 -preset fast -c:a aac -b:a 320k 15940407_cfr.mp4
   ```

### 3.2 프로젝트 · 시퀀스

- 원본을 프로젝트 패널로 가져온 뒤 **패널 오른쪽 아래 '새 항목' 아이콘 위로 드래그** → 원본과 똑같은 해상도 ·
  프레임레이트(보통 1920×1080, 60fps)의 시퀀스가 만들어집니다.
- PC가 버벅이면 **프록시**: 클립 우클릭 → 프록시 → 프록시 만들기 → 'H.264 Low Resolution Proxy' →
  프로그램 모니터의 '프록시 전환' 버튼(버튼 편집기 `+`에서 추가). 내보낼 때는 자동으로 원본이 쓰입니다.
- 미디어 캐시와 프로젝트는 SSD에 둡니다 (편집 > 환경 설정 > 미디어 캐시).

## 4. 1차 셀렉트 — 어느 구간을 쓸지

### 4.1 채팅 반응으로 후보 뽑기 (`chzzk_highlights.py`)

치지직 채팅 리플레이 전체를 받아서 **평소보다 채팅이 튀는 순간**을 찾고, 후보 구간만 이어 붙인 프리미어 시퀀스를
만들어 줍니다. 파이썬 3.8 이상이면 추가 설치 없이 돌아가고, 원본 파일을 주면 ffmpeg으로 음량(비명 · 폭소)과
무음(자리 비움)까지 봅니다.

```bash
python stream_edit/chzzk_highlights.py https://chzzk.naver.com/video/15940407 --vod D:/vod/15940407.mp4
```

OBS 녹화본을 쓸 때는 탐색기에서 파일을 Shift+우클릭 → **경로로 복사** 한 것을 `--vod` 뒤에 그대로 붙여 넣으면 됩니다
(따옴표가 같이 복사되므로 공백 · 한글 경로도 그대로 됨):

```powershell
python stream_edit\chzzk_highlights.py 15940407 --vod "C:\Users\<사용자>\Videos\2026-10-30 23-07-44.mp4"
```

채팅 시간은 치지직 다시보기 기준이라, 녹화를 방송과 다른 시각에 시작했으면 그만큼 어긋납니다. 파일명이 OBS 기본
형식이면 녹화 시작 시각과 방송 시작 시각의 차이로 **자동으로 맞추고**, 실행 첫머리에 `시간 맞춤: 다시보기 시간 =
녹화 시간 +14초`처럼 알려 줍니다. 그러면 결과의 모든 시간과 XML이 녹화 파일 기준이 됩니다. 후보가 전부 일정하게
밀려 있으면, 다시보기에서 한 장면의 시각 A와 녹화 파일에서 같은 장면의 시각 B를 재서 `--offset (A−B 초)`를 줍니다.

`highlights_15940407/` 폴더에 생기는 것:

| 파일 | 내용 |
|---|---|
| `highlights.md` | 후보 목록 — 점수순(쓸 가능성 순)과 시간순, 반응 종류, 추천 편집, 대표 채팅 |
| `premiere_selects.xml` | 후보 구간만 시간순으로 이어 붙인 시퀀스 → 이게 `01_셀렉트`의 출발점 |
| `premiere_markers.xml` | 원본 전체 + 후보 · 삭제 후보 위치 마커 |
| `cut_candidates.csv` | 채팅이 끊긴 구간 · 무음 구간 (삭제 후보) |
| `chat_density.svg` | 방송 전체 채팅 그래프 (브라우저로 열기) |
| `timeline.csv` | 5초 단위 원자료 (엑셀) |

읽는 법:

- **반응 시작** 칸은 채팅이 늘기 시작한 시각입니다. 채팅은 장면보다 늦으므로 **실제 장면은 보통 5~20초 앞**에 있습니다.
- **반응** 칸(웃음 · 놀람 · 당황 · 감동 · 클립 · 응원 · 후원 · 대화)이 [6장 효과](#6-효과-레시피)를 고르는 기준이 됩니다.
  특히 '클립'은 시청자가 직접 "클립 각"이라고 한 곳이라 우선순위가 높습니다.
- 후보가 모자라면 `--min-z 1.5`, 구간이 짧으면 `--pre 60 --post 20`, 더 많이 보려면 `--top 50`.
- 프리미어에서: 파일 > 가져오기(Ctrl+I) → XML 선택 → '미디어 연결' 창이 뜨면 원본 파일 지정.
- 영상 프레임레이트가 60이 아니면 `--vod`를 주거나 `--fps 30`처럼 맞춰야 마커 위치가 정확합니다.

### 4.2 후보 검토

1. `01_셀렉트`를 처음부터 보면서 후보마다 **남김(빨강) / 보류(노랑) / 삭제** 를 정합니다. 재밌는 장면은 대부분
   첫 시청에서 판단됩니다 — 오래 고민되면 보류.
2. 남길 후보는 앞뒤를 **설정 → 결과** 단위로 다듬습니다. 앞이 모자라면 `00_원본`에서 더 가져옵니다.
3. 채팅이 안 터지는 **흐름 구간**(목표 설명, 중간 결과, 엔딩 멘트)은 `00_원본`을 2배속으로 훑으며 찾아 추가합니다.
4. 콜드 오픈 후보는 주황, 썸네일 프레임은 청록 마커.
5. 목표: 35~45분.

### 4.3 대본으로 찾기 (텍스트 기반 편집)

창 > 텍스트 > **대본(Transcript)** 탭 → Transcribe(언어: 한국어). 방송 전체 전사는 오래 걸리므로 `01_셀렉트`
시퀀스만 전사해도 충분합니다.

- 검색창에 "미쳤", "잠깐", "아니", "대박" 같은 말을 넣어 리액션 위치를 찾습니다.
- 대본에서 문장을 드래그해 지우면 타임라인에서도 그 부분이 잘립니다 (잔물결 삭제). 저챗 구간 정리에 특히 빠릅니다.

## 5. 러프컷 → 파인컷

### 5.1 러프컷 (→ 24~26분)

1. `01_셀렉트`를 복제해 `02_러프컷`. 빨강만 남기고 노랑은 맨 뒤로 빼 둡니다.
2. [1장 구성안](#1-20분-구성안)의 챕터 순서대로 배치 — 대부분 이미 시간순이라 자르기 위주입니다.
3. **콜드 오픈**: 주황 마커 장면을 Alt+드래그로 복제해 맨 앞에 3~8초씩 붙이고, 결과가 나오기 직전에서 자릅니다.
4. 길이가 26분을 넘으면 점수 낮은 후보부터 뺍니다 (`highlights.md` 점수순 표 참고).

### 5.2 파인컷 (→ 20~21분)

- **점프컷**: 문장 사이 0.3초 넘는 공백, "어… 음…" 을 지웁니다. 공백 시작에서 Ctrl+K → 말이 다시 시작하는 곳에
  재생헤드 → **Q** (앞부분이 잘리고 뒤가 당겨짐). 이 두 동작만 반복하면 됩니다.
- **공백 일괄 삭제**: 시퀀스 대본(소스 대본에서는 안 됨)에서 필터 → **일시 정지(Pauses)** → 전부 강조되면
  **추출(Extract)** 로 한 번에 지웁니다. 영어가 아닌 언어에서 문장째 지워졌다는 보고가 있고, 기계적으로 다 지우면
  말이 숨 막히게 붙으니 결과를 꼭 다시 봅니다.
- **여운은 남깁니다**: 펀치라인 뒤 리액션 0.3~0.7초(20~40프레임)는 자르지 않습니다.
- **틱 소리 제거**: 오디오를 자른 자리에서 '틱' 소리가 나면 2~3프레임 오디오 크로스페이드를 겁니다. 편집 > 환경 설정 >
  타임라인 > '오디오 전환 기본 지속 시간'을 3프레임으로 → 타임라인 왼쪽 위 '연결된 선택' 끄기 → A1 클립만 드래그로
  선택 → Shift+D.
- **J컷 / L컷**: 장면이 바뀌는 곳에서 다음 장면 소리를 6~12프레임 먼저 시작하면(J컷) 이음새가 부드럽습니다.
  Alt를 누른 채 오디오 클립 가장자리를 드래그하면 오디오만 늘어납니다.

### 6.1 펀치인 줌 (가장 많이 씀)

웃음 포인트에서 화면이 "툭" 커지는 컷 줌입니다. 키프레임이 없어서 빠릅니다.

1. 줌 시작과 끝에서 Ctrl+K로 자릅니다 (보통 펀치라인 시작 ~ 리액션 끝, 1~3초).
2. 가운데 조각을 선택 → 효과 컨트롤(Effect Controls) > 동작(Motion) > 비율 조정(Scale) **115~130**.
3. 위치(Position)로 얼굴이나 대상이 화면 중앙에 오게 옮깁니다.
4. 효과 컨트롤의 '동작'을 우클릭 → 사전 설정 저장 → "펀치인 125". 다음부터는 효과 패널 > 사전 설정에서 드래그.

1080p 원본은 130%를 넘으면 흐려지기 시작합니다. 크게 보여줘야 하면 6.3 얼굴캠 확대를 씁니다.

### 6.2 부드러운 줌

긴장감 · 진지한 순간 · 감동에는 천천히 밀고 들어가는 줌이 어울립니다.

1. 시작점에서 비율 조정 옆 스톱워치(애니메이션 켜기) 클릭 → 100.
2. 2~4초 뒤로 이동 → 110. (빠른 강조 줌은 8~10프레임 동안 100 → 120)
3. 두 키프레임 선택 → 우클릭 → 시간 보간 > **천천히 들어오기 / 천천히 나가기** (Ease In / Ease Out).

빠른 줌에 모션 블러를 넣으려면 '동작' 대신 효과 > 왜곡 > **변형(Transform)** 의 비율을 쓰고,
'컴포지션의 셔터 각도 사용'을 끈 뒤 셔터 각도 180.

### 6.3 얼굴캠 확대

방송 화면 구석의 작은 얼굴캠을 리액션 순간에 크게 띄웁니다.

1. 원본 클립을 Alt+드래그로 V2에 복제 (리액션 구간만).
2. V2 클립에 효과 > 변형 > **자르기(Crop)** → 얼굴캠만 남게 상하좌우를 자름.
3. 비율 180~250, 위치를 화면 가운데나 반대편으로.
4. 효과 > 원근 > **드롭 섀도** 로 테두리감, 등장할 때 비율 0 → 110 → 100 (6프레임) 팝.
5. 더 집중시키려면 V1에 가우시안 흐림(흐림 정도 20).

### 6.4 화면 흔들림

비명 · 충격 · 쾅 하는 순간. 조정 레이어에 걸면 아래 모든 트랙이 같이 흔들립니다.

1. 프로젝트 패널 > 새 항목 > **조정 레이어** → V3에 0.3~0.6초 길이로 놓기.
2. 효과 > 왜곡 > 변형 → 위치 키프레임을 2프레임 간격으로: (960,540) → (978,530) → (944,552) → (970,536) →
   (952,546) → (960,540). 비율 105 (가장자리 검은 테두리 숨김), 셔터 각도 180.
3. 변형 효과 우클릭 → 사전 설정 저장 → 유형 'Anchor to In Point(시작 지점 기준)' → "흔들림".
   이후 조정 레이어에 드래그만 하면 됩니다.

### 6.5 프리즈 프레임 + 흑백 + 정적

황당 · 어이없음 · "이때까지만 해도 몰랐다" 연출.

1. 멈출 프레임에 재생헤드 → 클립 우클릭 → **프레임 고정 세그먼트 삽입** (Insert Frame Hold Segment).
2. 정지 구간 길이를 1~2초로 조정.
3. 정지 구간에 Lumetri 색상 > 기본 교정 > 채도 0 (또는 효과 '흑백').
4. 오디오는 비우거나 레코드 긁는 효과음 하나. 자막: "???", "이때까지만 해도…".

### 6.6 슬로우 리플레이

대박 플레이 · 놀람 · 결정적 순간을 한 번 더.

1. 핵심 2~4초를 I/O로 지정해 복사(Ctrl+C) → 그 장면이 끝나는 곳에 재생헤드 → **Ctrl+Shift+V** (삽입 붙여넣기).
2. 붙인 클립 선택 → Ctrl+R → 속도 **50%**, '잔물결 편집, 후행 클립 이동' 체크. 60fps 원본이면 50%도 부드럽습니다.
3. 오디오는 끄고(느린 목소리는 어색함) 효과음이나 BGM으로 채웁니다.
4. 비율 115 + 화면 위에 "REPLAY" 자막 + 앞에 '되감기' 효과음.

### 6.7 배속 몽타주 + 시간 경과

파밍 · 연습 · 반복 도전 · 이동처럼 결과만 중요한 구간.

1. 구간을 선택 → Ctrl+R → 400~1000% (정확한 길이에 맞출 땐 R 속도 조정 도구로 끝을 끌기).
2. 오디오는 끄고 경쾌한 BGM. 화면 왼쪽 위에 "×8 ▶▶" 자막.
3. 몽타주가 끝나면 검은 화면 1~1.5초 + "2시간 뒤…" 자막 (또는 '검정으로 물들이기' 전환).
4. 반복 도전은 배속 대신 실패 장면 3~4개를 2~3초씩 이어 붙이고 "도전 7회차" 카운터 자막을 다는 쪽이 더 웃깁니다.

### 6.8 강조 (원 · 화살표 · 스포트라이트)

- **원 · 화살표**: 프로그램 모니터에서 펜 · 사각형 · 타원 도구로 그리기 → 칠 없음, 선 빨강 8px → 0.2초 팝 등장.
- **스포트라이트**: 조정 레이어 + Lumetri 색상 > 노출 -1.5 → 효과 컨트롤의 Lumetri에서 타원 마스크 → '반전' 체크
  → 마스크 밖만 어두워집니다. 미니맵 · 점수판 · 채팅 같은 작은 부분을 보여줄 때.

### 6.9 채팅 · 후원 오버레이

1. 치지직 다시보기에서 해당 시각의 채팅창을 캡처 (Win+Shift+S) → PNG 저장 → V4로.
2. 자르기(Crop)로 필요한 줄만 남기고, 위치 키프레임으로 오른쪽에서 6프레임 동안 밀고 들어오게.
3. 2~3초 유지. 닉네임이 문제 될 만하면 모자이크.
4. 후원은 금액 · 문구가 보이게 크게 → 바로 뒤 스트리머 리액션은 6.1 펀치인.

### 6.10 블러 · 모자이크

실명 · 연락처 · 주소 · 결제 정보 · 메신저 알림 · 다른 방송 화면 · 시청자 닉네임.

1. 효과 > 스타일화 > **모자이크** (가로 · 세로 블록 40) 또는 흐림 및 선명 > **가우시안 흐림** (흐림 정도 40 이상).
2. 효과 컨트롤의 해당 효과 아래 사각형 · 펜 마스크로 영역 지정, 마스크 페더 10.
3. 대상이 움직이면 마스크 경로의 **'선택한 마스크를 앞으로 추적'** ▶ 버튼.

### 6.11 전환

- 기본은 **하드컷**입니다. 전환 효과를 남발하면 영상이 오래돼 보입니다.
- 챕터가 바뀔 때: 흰색으로 물들이기 6~8프레임 + '휙' 효과음.
- 시간이 흐를 때: 검정으로 물들이기 15프레임 + "N시간 후" 자막.
- 효과 패널에서 자주 쓰는 전환을 우클릭 → '선택한 전환을 기본 전환으로 설정' → 이후 Ctrl+D.

### 6.12 효과 밀도

| 항목 | 1분당 |
|---|---|
| 강조 자막 | 4~8개 |
| 효과음 | 2~4개 |
| 줌 (펀치인 포함) | 3~6개 |
| 리플레이 · 프리즈 같은 큰 효과 | 1개 이하 |

콜드 오픈과 클라이맥스에 몰아 쓰고, 대화 구간은 비워 둡니다. 모든 웃음에 효과를 붙이면 진짜 큰 순간이 묻힙니다.

## 7. 자막

### 7.1 종류와 스타일

| 종류 | 위치 | 스타일 | 언제 |
|---|---|---|---|
| 기본 대사 | 하단 중앙 | 흰 글씨 + 검은 선 8~10, 크기 60~70 | 알아듣기 힘든 말, 핵심 대사 |
| 강조 (펀치라인) | 화면 중앙 · 말한 사람 근처 | 노랑 · 빨강, 크기 100~150, 굵은 선, 살짝 기울임 | 웃음 포인트 |
| 상황 설명 | 상단 | 반투명 검은 박스 + 흰 글씨 | 맥락, "편집자:" 코멘트 |
| 효과 · 속마음 | 자유 | 작게, 손글씨 느낌 | 의성어, 속마음 |
| 화자 구분 (합방) | — | 사람마다 색 고정 | 여러 명이 말할 때 |

상업적으로 무료인 글꼴: G마켓 산스 Bold, Pretendard ExtraBold, 검은고딕(Black Han Sans), 배민 도현체.

### 7.2 스타일을 만들어 재사용

1. 문자 도구(T) → 프로그램 모니터 클릭 → 입력.
2. 기본 그래픽(Essential Graphics) 또는 속성 패널 → 글꼴 · 크기 · 칠 · 선 · 그림자 설정.
3. 같은 패널의 스타일 메뉴 → **텍스트 스타일 만들기** → "자막_기본", "자막_강조", "자막_상황".
4. 이후 자막은 기존 자막 클립을 **Alt+드래그로 복제해 글자만 고치는** 게 가장 빠릅니다.

### 7.3 팝 애니메이션

강조 자막 클립 선택 → 효과 컨트롤 > 벡터 동작(Vector Motion) > 비율: 0 → 115 (4프레임) → 100 (3프레임).
효과를 사전 설정으로 저장('Anchor to In Point')하거나, 한 클립에 만든 뒤 다른 자막들에 Ctrl+C →
**Ctrl+Alt+V(특성 붙여넣기)** 로 복사합니다.

### 7.4 자동 캡션 → 유튜브 자막(SRT)

화면에 굽는 예능 자막과 별개로, 전체 대사 자막을 유튜브 자막 파일로 올리면 무음 시청자 · 검색에 도움이 됩니다.

1. 최종 시퀀스에서 창 > 텍스트 > 대본 → Transcribe (한국어).
2. 캡션 탭 → **대본에서 캡션 만들기** → 줄당 최대 글자 수 20 정도.
3. 오타 수정 (자동 전사는 게임 용어 · 닉네임을 자주 틀림).
4. 파일 > 내보내기 > 캡션 → SRT → 유튜브 업로드 때 자막 파일로 올림.

## 8. 사운드

### 8.1 목표 레벨

| 요소 | 레벨 |
|---|---|
| 원본 (대사 + 게임) | 피크 -3 dB 이하, 최종 -14 LUFS 근처 |
| 효과음 | 대사보다 3~6 dB 작게 |
| BGM — 말하는 동안 | -28 ~ -22 dB |
| BGM — 몽타주 · 대사 없음 | -18 ~ -14 dB |

- **원본 레벨 맞추기**: 원본 클립 모두 선택 → G (오디오 게인) → 최대 피크 정규화 -3 dB.
- **비명 · 갑자기 큰 소리**: 해당 부분만 클립 볼륨 키프레임으로 -6 dB.
- **음성 향상(Enhance Speech)** 은 게임 소리까지 지워 버리므로 게임 방송에는 쓰지 않습니다 (잡음 심한 저챗만).

### 8.2 효과음

- 펀치라인 직후 0~2프레임에 놓습니다. 미리 나오면 김이 샙니다.
- 같은 효과음을 반복하지 말고 3~4가지를 돌려 씁니다.
- 출처: 유튜브 스튜디오 > 오디오 보관함(효과음 포함), Pixabay. 출처 불명 '예능 효과음 모음'은 저작권 문제가 생길 수 있습니다.

### 8.3 BGM

1. BGM을 A3에 놓고 원본 클립은 기본 사운드(Essential Sound) 패널에서 **대화**, BGM은 **음악**으로 지정.
2. BGM 선택 → 기본 사운드 > 음악 > **더킹** 체크 → 대상: 대화 클립 → 더킹 양 -15 dB → **키프레임 생성**.
   말할 때 자동으로 BGM이 줄어듭니다.
3. 구간 길이에 맞추려면 기본 사운드 > 음악 > 지속 시간 > **리믹스** → 목표 길이 입력.
4. 챕터마다 분위기에 맞게 바꾸고(밝음 → 긴장 → 웅장 → 잔잔), 곡이 바뀌는 곳은 1초 크로스페이드.

### 8.4 최종 음량

내보내기 설정 > 효과 > **음량 정규화** (Loudness Normalization) → ITU BS.1770-3, 대상 음량 **-14 LUFS**,
최대 실제 피크 **-1 dBTP**. 유튜브 기준 음량에 맞춰져 다른 영상보다 작거나 크게 들리지 않습니다.

## 10. 저작권 · 정책 체크

- **방송 중 튼 음악**(BGM · 노래 · 리액션 영상 소리)은 Content ID에 걸려 수익 창출 불가 · 차단될 수 있습니다.
  그 구간은 음소거 · 삭제 · BGM 교체. 방송 내내 음악이 깔려 있었다면 목소리와 분리하기 어려우니 업로드 단계의
  저작권 검사 결과를 꼭 확인합니다.
- **다른 사람 영상 · 방송 화면**을 길게 보여주면 저작권 · 재사용 콘텐츠 정책에 걸립니다. 짧게, 작게, 리액션 위주로.
- **게임**은 대부분 수익화를 허용하지만 게임사 영상 정책을 확인하고, 컷신을 통째로 길게 쓰지 않습니다.
- **다른 사람 방송을 편집**한다면 스트리머의 허락 · 2차 창작 가이드라인을 먼저 확인합니다.
- **합방 상대 · 게스트**의 출연 동의, 시청자 닉네임 노출 최소화.
- **방송을 거의 그대로** 올리면 '재사용된 콘텐츠'로 수익 창출이 거절될 수 있습니다. 구성 · 자막 · 편집으로 가치를 더한 영상이어야 합니다.

## 12. 업로드

- **썸네일**: 클라이맥스나 '클립' 반응이 가장 컸던 장면에서 Ctrl+Shift+E (프레임 내보내기, PNG) → 표정 크게 +
  3~6글자 큰 문구, 1280×720.
- **제목**: 가장 센 순간을 결과 직전까지만 ("○○하다가 생긴 일").
- **챕터**: 최종 시퀀스의 녹색 마커 → 파일 > 내보내기 > 마커(CSV, 깨지면 HTML) → 설명란에 `00:00 오프닝`처럼
  붙여 넣기. 첫 줄은 반드시 00:00, 3개 이상, 각 10초 이상이어야 유튜브가 챕터로 인식합니다.
- **설명란**: 원본 방송 링크 · 날짜, 음원 출처.
- **최종 화면**: 마지막 20초에 다음 영상 · 구독 요소 (그래서 엔딩 20초를 비워 둠).
- **중간 광고**: 자동 배치 대신 챕터 경계에 수동 배치.
- **자막**: 7.4에서 만든 SRT 업로드.
- 공개 전 '확인' 단계에서 **저작권 검사** 결과 확인.

## 13. 최종 검수 체크리스트

- [ ] 첫 30초 안에 이 영상의 가장 센 장면이 나온다
- [ ] 길이 19:30~21:00, 마지막 20초는 최종 화면용
- [ ] 컷 사이 '틱' 소리, 갑자기 커지는 소리가 없다
- [ ] 자막 오타 · 화면 밖으로 나간 자막이 없다 (프로그램 모니터 렌치 아이콘 > 안전 여백)
- [ ] 개인정보 · 저작권 구간(자주 마커)을 모두 처리했다
- [ ] 효과음이 대사보다 크지 않다, BGM 때문에 대사가 묻히지 않는다
- [ ] 챕터 마커와 설명란 타임스탬프가 맞다
- [ ] 휴대폰으로 한 번 끝까지 본다 (작은 화면에서 자막 크기 · 줌 확인)
