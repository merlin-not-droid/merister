> 스포츠 마케팅 에이전시 Meister의 홈페이지 기획 문서입니다. 브랜드 전략, 웹 기획, UX/UI 관점에서 정리했습니다.
> 이 문서의 내용은 `meister/` 폴더의 TSX 사이트에 그대로 구현되어 있습니다.
> **[자료 필요]** 표시는 실제 자료가 들어와야 하는 자리이고, **(제안)** 표시는 확정되지 않아 Meister가 제안하는 내용입니다.

| 포지셔닝 문장 | 스포츠 현장을 이해하고, 브랜드의 관점으로 기획하는 파트너 | (제안) |

| 에이전트 업무(이적·연봉 협상) | 종목별 자격 요건 확인 후 결정 | 미정 — 사이트에 명시 |

### 1-2. 브랜드 원칙 (사이트 Home ‘Our Position’, About ‘How we work’)

1. **Field Sense — 현장을 아는 기획**: 경기 일정, 동선, 안전, 팬의 하루까지 실제 현장 조건을 기준으로 계획합니다.
2. **Brand Logic — 브랜드 목표에서 출발**: 무엇을 알리고 누구와 관계를 맺을지 먼저 정하고, 노출이 아니라 목표에 맞는 경험을 설계합니다.
3. **Honest Scale — 약속한 만큼 정확하게**: 할 수 있는 일과 필요한 파트너를 처음부터 투명하게 말합니다.

### 1-3. 말투 (Tone of Voice)

- 전문적이되 쉬운 말. 업계 용어는 처음 나올 때 풀어 쓴다. (예: 액티베이션 → “계약 이후 실제로 사람들이 경험하는 활동”)
- 형용사보다 동사. “최고의, 혁신적인” 대신 “찾고, 설계하고, 실행합니다”.
- 약속은 구체적으로, 실적은 정직하게. 회사 명의 실적이 없다는 사실을 숨기지 않는다.
- 한국어 기본, 메뉴·섹션 라벨·짧은 슬로건에 영어.

## 3. 추천 사이트맵과 페이지 역할

### 3-1. 기본안 검토 결과

제시하신 6페이지 구성은 방향이 맞습니다. 다만 창업 초기 콘텐츠 분량을 고려해 아래처럼 조정했습니다.

- **Services는 한 페이지 + 서비스별 앵커**로 구성 (서비스가 3개뿐이므로 하위 페이지로 나누면 빈 페이지가 생김)
- **Portfolio → Work**로 이름 변경: 완료 실적이 아니라 ‘제안 프로젝트 + 창업자 경험’을 함께 담기 때문
- **Insights는 구조만 먼저 완성**: 글 3편이 확정되기 전까지 메뉴 노출을 보류할 수 있도록 데이터 파일 하나로 관리
- **개인정보 처리방침** 페이지 추가 (문의 폼 동의 항목에서 연결 필요)

### 3-2. 사이트맵

```
/                         Home       — 첫인상, 3가지 질문에 대한 요약 답변, 문의 유도
├─ /about                 About      — 회사 소개, 미션·비전, 창업자, 일하는 방식
├─ /services              Services   — 3개 서비스 상세 (#sponsorship #events #athletes) + FAQ
├─ /work                  Work       — 유형 범례 + 필터(전체/제안/창업자/회사)
│   └─ /work/:slug                   — 목적 · 역할 · 실행(안) · 결과(기대 효과)
├─ /insights              Insights   — 카테고리 필터(트렌드/사례/관점)
│   └─ /insights/:slug               — 글 상세, 출처 표기
├─ /contact               Contact    — 문의 폼, 직접 연락처, 응답 절차
└─ /privacy               개인정보 처리방침
```

### 3-3. 페이지별 역할

| 페이지 | 역할 | 핵심 콘텐츠 | 주 CTA |
|---|---|---|---|
| Home | 10초 안에 “누구·무엇·어떻게 연락”을 이해시키기 | 헤드라인, 포지션, 방문자 라우터, 서비스, 플레이북, 제안 프로젝트, 인사이트, CTA | 협업 문의하기 |
| About | 창업 초기 회사의 신뢰를 ‘사람과 방식’으로 형성 | 회사 개요(창업 준비 단계 명시), 미션·비전, 창업자 [자료 필요], 원칙 4개, 프로세스 | 협업 문의 |
| Services | 방문자가 자기 문제에 맞는 서비스를 찾고 범위를 이해 | 서비스별 주요 고객 / 해결하는 문제 / 제공 업무(제안 표시) / 산출물, FAQ | 서비스별 문의(관심 서비스 자동 선택) |
| Work | 실적이 없는 단계에서 사고방식과 기획력을 증명 | 제안 프로젝트 3개, 창업자 경력 자리, 회사 프로젝트(준비 중) | 이 제안을 실행하고 싶다면 문의 |
| Insights | 전문성 축적, 검색 유입 | 관점 글 3편(초안) | 문의 |
| Contact | 문의 확보 | 5개 입력 + 동의, 응답 절차 4단계 | 문의 보내기 |

## 5. 디자인 방향 3가지

> 사이트 왼쪽 아래 팔레트 버튼(검토용)으로 세 방향을 실제 화면에서 바로 비교할 수 있습니다. 주소에 `?direction=b` 처럼 붙여 공유할 수도 있습니다.

### A. Floodlight — 야간 경기장 (추천)

- **콘셉트**: 야간 경기의 조명 아래 선명해지는 순간.
- **색상**: Ink `#0B0D0B` · Paper `#F1F1EB` · Volt `#C6FF33` (밝은 배경에서 강조 텍스트는 `#3D5A00`)
- **서체**: Archivo(좁은 폭 72%, 굵게, 대문자) + Pretendard
- **추천 이유**: 역동성(조명·대비)과 신뢰(절제된 흑백 + 한 가지 강조색)를 동시에 표현. 사진이 부족한 초기에도 타이포그래피만으로 힘이 있음. 디지털·모바일에서 강한 인상.
- **리스크**: 볼트 컬러는 스포츠 업계에서 흔한 편 → 로고·사진 톤·전광판 모티프로 차별화.

### B. Matchday Paper — 경기 프로그램북

- **콘셉트**: 경기 프로그램북과 전술 노트 같은 에디토리얼.
- **색상**: Pitch Green `#0F2A20` · Paper `#F3EFE6` · Signal Orange `#FF5B1F` (밝은 배경 강조 텍스트 `#B83D0B`)
- **서체**: Instrument Serif(이탤릭 강조) + Pretendard
- **이유**: 기획력·지적인 인상, 제안서·인사이트 중심 회사에 어울림. 기업 담당자에게 차분한 신뢰감.
- **리스크**: 역동성이 약해질 수 있음 → 사진과 모션으로 보완 필요.

### C. Club Navy — 클래식 클럽

- **콘셉트**: 전통 있는 클럽의 신뢰감 + ‘Meister(장인)’를 상징하는 골드.
- **색상**: Navy `#0A1430` · Paper `#F4F6FA` · Trophy Gold `#E9C25B` (밝은 배경 강조 텍스트 `#7F5C0B`)
- **서체**: Unbounded(넓은 폭) + Pretendard, 둥근 버튼
- **이유**: 구단·협회·기업 등 보수적인 의사결정자에게 안정감. 프리미엄 인상.
- **리스크**: 금융·컨설팅처럼 보일 수 있음 → 스포츠 사진 비중을 높여야 함.

### 공통 원칙

- 장식보다 타이포그래피·여백·사진. 강조색은 한 화면에 한 가지.
- 어두운 섹션(Ink)과 밝은 섹션(Paper)을 교차해 정보 위계와 리듬을 만듦.
- 애니메이션은 opacity/transform 위주, 한 번 재생 후 멈춤. `prefers-reduced-motion` 사용자는 모든 움직임 최소화.
- WebGL은 페이지당 1개(Home Hero), 화면 밖·탭 비활성 시 정지.

## 6. 메인 헤드라인과 소개 문구 초안

**채택안 (사이트 적용)**

- 영문 슬로건: **From the Field, For the Brand.**
- 국문 헤드라인(H1): **스포츠의 감동을, 브랜드의 경험으로.**
- 소개 문구: Meister는 스폰서십, 스포츠 이벤트, 선수 매니지먼트를 기획하고 실행하는 스포츠 마케팅 에이전시입니다. 경기장의 흐름을 이해하고, 브랜드의 목표에서 출발합니다.
- 포지션 문단: 우리는 경기장의 열기와 선수의 이야기, 팬의 응원이 브랜드와 만나는 지점을 찾습니다. 그리고 그 순간이 오래 기억되도록 설계하고, 현장에서 직접 실행합니다.

**대안**

## 10. 우선 확인이 필요한 질문 (기획에 큰 영향)

1. **창업자 경력 공개 범위** — 실명·사진·이전 소속을 공개할 수 있나요? (About과 Work의 신뢰 형성 방식이 달라집니다)
2. **선수 매니지먼트의 범위와 주력 종목** — 특정 종목(예: 축구, 농구)에 집중하나요? 에이전트 자격이 필요한 업무를 할 계획인가요?
3. **디자인 방향** — A/B/C 중 어떤 방향이 가장 가까운가요? (사이트에서 바로 비교 가능)
4. **문의 수신 방식** — 폼 수신 서비스를 쓸지, 이메일만 받을지. 회신 기준(현재 ‘영업일 2일’로 가정)도 확인이 필요합니다.

## 11. 적용한 가정

- 활동 지역은 서울로 가정했습니다.
- 회신 기한을 ‘영업일 기준 2일’, 첫 미팅을 ‘30분’으로 가정했습니다.
- 개인정보 보유 기간을 ‘문의 처리 완료 후 1년’으로 가정했습니다. (법률 검토 필요)
- 제안 프로젝트 3개는 Meister의 자체 기획안이며 실제 고객·수치가 없습니다. 화면에 ‘제안 프로젝트 · 미실행’, 결과 항목은 ‘기대 효과 (실제 결과 아님)’으로 표시합니다.
- 인사이트 3편은 Meister의 관점 글 초안이며 수치·사례를 인용하지 않았습니다. ‘초안 · DRAFT’로 표시합니다.
- 존재하지 않는 고객사, 파트너 로고, 실적, 수상 이력, 고객 후기는 사용하지 않았습니다.
